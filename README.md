
## 📰 News-to-Feed

**News-to-Feed** is a smart and interactive web application that collects and displays the latest news from around the world using **NewsAPI**. Users can **search news by topic or date**, read old articles, and enjoy features that make information more **accessible and personalized**.

### ✨ Features

* 🌍 **Global News Feed** — Fetches news from various countries and categories.
* 🕒 **Search & History** — Search news by name or date and access older articles easily.
* 🌐 **Language Translation** — Instantly translate the entire website into the user’s preferred language.
* 🔊 **Text-to-Speech** — Users can listen to the news in their chosen language with a single click.
* 📰 **Category Selection** — Choose the type of news articles to view personalized results.
* 🌦️ **Smart-Weather Module** — Displays current weather and up to 7-day forecasts, auto-detecting the visitor’s location (powered by **OpenWeatherMap**).
